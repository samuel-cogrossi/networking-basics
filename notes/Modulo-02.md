> All computers connected to a network that participate directly in
> network communication are classified as hosts.

Can send and receive messages on the network

Can act as a

> Client \_ host that an software allows to request and display
> information obtained from a server

Server \_ host that an software allows to provide information to other
hosts

Both \_ is called a peer-to-peer (P2P) network.

Internet Service Provider (ISP)

link between the home provider and the network

> are connected in a hierarchical manner that ensures that internet
> traffic generally takes the shortest path from the source to the
> destination.
>
> Each ISP connect to other ISP to form a network of links that
> interconnect users
>
> ex: Claro, Vivo, …

Modem

a device that connect devices of a private network to a ‘ISP server’

often connected to a router
