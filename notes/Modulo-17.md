Network Commands

ipconfig \_

display basic configuration information

/all \_ additional information

/release \_ remove his current IP address

/renew \_ remove his current IP address and request a new one

ping \_

sends a few packets to one location to see if the connection is working

netstat \_

display active network connections

HTTPs \_ 443

HTTP \_ 80

socket \_ combination of IP address and a port number
